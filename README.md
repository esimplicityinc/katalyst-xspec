# Katalyst XSpec

Internal monorepo for Playwright BDD testing utilities and scaffolding.

## Packages

| Package | Description |
|---------|-------------|
| **@esimplicityinc/katalyst-xspec** (`katalyst-xspec/`) | Reusable fixtures, ports, adapters, and step definitions for API/UI/TUI testing |
| **@esimplicityinc/create-katalyst-xspec** (`create-katalyst-xspec/`) | CLI to scaffold a new Playwright-BDD test project |

## Quick Start

```bash
# Install dependencies
npm install

# Build the library
npm run build -w @esimplicityinc/katalyst-xspec

# Scaffold a new test project
npx @esimplicityinc/create-katalyst-xspec my-tests
```

## Architecture

The framework uses a **Ports and Adapters** pattern:

```
Feature Files (.feature)
        |
        v
  Step Definitions
        |
        v
     Ports (interfaces)
        |
        v
   Adapters (implementations)
        |
        v
  Playwright / tui-tester
```

### Available Ports

- **ApiPort** - HTTP API testing
- **UiPort** - Browser UI testing
- **TuiPort** - Terminal UI testing
- **AuthPort** - Authentication handling
- **CleanupPort** - Test data cleanup

### Tag System

| Tag | Description |
|-----|-------------|
| `@api` | API-only scenarios |
| `@ui` | Browser UI scenarios |
| `@tui` | Terminal UI scenarios |
| `@hybrid` | Cross-layer scenarios |

## Agent Skills

Katalyst BDD includes [Agent Skills](./docs/guides/agent-skills.md) for AI-assisted development. These help AI coding assistants (OpenCode, Claude Code, Cursor) understand the framework and generate better tests.

```bash
# Install with Agent Skills
npx @esimplicityinc/create-katalyst-xspec --with-skills

# Update skills in existing project
npx upgrade-katalyst-xspec --update-skills
```

## Upgrading

The framework includes powerful upgrade and migration tools:

```bash
# Check for updates
npm run check-updates

# Simple package upgrade
npm run upgrade

# Full scaffolding migration (preserves custom files)
npm run upgrade:migrate

# Interactive upgrade mode
npx upgrade-katalyst-xspec -i

# Generate step stubs for missing steps
npm run gen:stubs
```

See the [Upgrading Guide](./docs/guides/upgrading.md) for details.

## Installation

Both packages are published to **GitHub Packages** (not npmjs.com).

1. Map the scope in your project's `.npmrc` (projects generated by `create-katalyst-xspec` already have this):

```
@esimplicityinc:registry=https://npm.pkg.github.com
```

2. Authenticate with a GitHub token that has the `read:packages` scope, in your user `~/.npmrc`:

```
//npm.pkg.github.com/:_authToken=<your_github_token>
```

In GitHub Actions, use `actions/setup-node` with `registry-url: https://npm.pkg.github.com`, `scope: '@esimplicityinc'`, and `NODE_AUTH_TOKEN: ${{ secrets.GITHUB_TOKEN }}`.

3. Install or scaffold:

```bash
npm install -D @esimplicityinc/katalyst-xspec

# or scaffold a new project
npx @esimplicityinc/create-katalyst-xspec my-tests
```

### Migrating from `@esimplicity/stack-tests`

0.4.0 renamed the packages. In an existing project, run:

```bash
npx -p @esimplicityinc/create-katalyst-xspec upgrade-katalyst-xspec
```

It adds the `.npmrc` scope line, rewrites `@esimplicity/stack-tests` imports in `features/` and `playwright.config.*`, and swaps the dependency.

## Publishing

Publishing a **GitHub Release** (or manually running the `Publish Packages` workflow) publishes both packages to GitHub Packages using the built-in `GITHUB_TOKEN`. No secrets are required.
